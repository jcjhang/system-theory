## 0. 一張地圖：整門課只在解一個問題

$$\min_{u}\; J = \underbrace{\phi(x_{\text{終點}})}_{\text{終點成本}} + \sum \text{或} \int \underbrace{L(x, u)}_{\text{沿路成本}} \qquad \text{同時遵守 } \underbrace{x_{k+1} = f(x_k, u_k)\ \text{或}\ \dot x = f(x, u)}_{\text{系統的規則}}$$

解這個問題有**兩大思路**：

| | 思路 A：變分法 / 三個條件 | 思路 B：Bellman / 動態規劃 |
|---|---|---|
| 問的問題 | 從**這個**起點出發，最佳的**那一條**軌跡長什麼樣？ | 從**任何**狀態出發，剩下最少要付多少？ |
| 核心工具 | Hamiltonian + 共態 $\lambda$ | cost-to-go $J^*(x)$ 或 $V(x)$ |
| 章節 | Lewis Ch 1、2、3；Żak Ch 5 的 E-L、PMP | Lewis Ch 6、11；Żak Ch 5 的 HJB |
| 答案的形式 | 通常是開迴路 $u^*(t)$ | 天生是回授 $u^*(x)$ |

**兩條路的交會點是 LQR**：線性系統 + 二次成本時，兩邊都會得到同一條 **Riccati 方程**。

**兩條路之間的橋**：
$$\lambda = \frac{\partial J^*}{\partial x}$$
共態就是 cost-to-go 的斜率，也就是「狀態多一單位，剩下的成本多多少」。看懂這一行，整門課就串起來了。

**Ch 11 的位置**：解的還是思路 B 的 Bellman 方程，只是把「用模型算出下一個狀態」換成「實際走一步去量」。

**Żak Ch 3、4 的位置**：控制之前先問兩件事——系統**控制得動**、**看得到**嗎（Ch 3）？閉迴路會**穩定**嗎（Ch 4）？

## 1. Lewis Ch 1：Lagrange multiplier 與 Hamiltonian

### 為什麼需要 $\lambda$？

有約束時，變數不能各自亂動：動了一個，另一個就被約束綁著一起動。$\lambda$ 的作用是**把「被綁住」這件事吸收掉**，讓你可以假裝每個變數都是自由的，各自微分 $= 0$。

### 三兄弟

$$H = L + \lambda^T f, \qquad H_\lambda = 0\ (\text{就是約束本身}),\quad H_x = 0,\quad H_u = 0$$

- 有幾個未知數就配幾條方程：$x$、$u$、$\lambda$ 各一條
- 如果題目的兩個變數**地位相同**（例如長和寬），就不用分 $x$、$u$，對每個變數都微分 $= 0$ 即可
- 解聯立時常用的技巧：**兩條式子都含 $\lambda$ 時，相除或相減把 $\lambda$ 消掉**

### $\lambda$ 的意義：約束的價格

約束放鬆一點點，最小成本會變多少，大小就是 $\lvert\lambda^*\rvert$（正負號看約束怎麼寫）。這個意義到 Ch 2、3 會變成「狀態的價格」。

### 幾何意義：等高線與約束「相切」

- **等高線** = 讓 $L$ 等於某個常數的所有點。畫幾條不同常數的等高線，就看得出 $L$ 往哪個方向變大
- **約束** = 一條曲線，只能在這條曲線上找答案
- 最佳點的特徵：**等高線剛好跟約束曲線相切**。如果是「穿過」而不是相切，沿著約束再走一點就能碰到更小的等高線
- 相切 ⇔ 兩個梯度**平行**：$\nabla L = -\lambda\nabla f$。這就是三兄弟的幾何版本
- 畫圖題要畫出：幾條等高線（標出 $L$ 變大的方向）、約束曲線、相切點，最好再畫出兩個梯度箭頭

### 確認是最小，不是最大

一階條件只找到「平的地方」。要確認是最小值：可以把約束代進去變成單變數函數，再看二階導數 $> 0$；或用直覺說明「往兩端走成本會變大」。

→ `midterm-prepare.md` §0.6、§1.2

## 2. Lewis Ch 2：離散時間最佳控制

### 從 Ch 1 到 Ch 2 多了什麼

狀態方程 $x_{k+1} = f(x_k, u_k)$ 在**每個時間點**都是一條約束，所以每個時間點配一個 $\lambda_{k+1}$。三兄弟就變成三組方程：

| 方程 | 從哪來 | 怎麼算 |
|---|---|---|
| 狀態方程 $x_{k+1} = \partial H^k/\partial\lambda_{k+1}$ | 約束本身 | 從 $x_0$ **順著時間** |
| 共態方程 $\lambda_k = \partial H^k/\partial x_k$ | 對 $x_k$ 微分 | 從 $\lambda_N$ **逆著時間** |
| 駐點條件 $0 = \partial H^k/\partial u_k$ | 對 $u_k$ 微分 | 每一步解出 $u_k$ |

其中 $H^k = L(x_k, u_k) + \lambda_{k+1}^T f(x_k, u_k)$。

### 為什麼共態方程是 $\lambda_k = \dots$ 而不是 $= 0$？

$x_k$ 出現在**兩個地方**：它是第 $k$ 步的起點（在 $H^k$ 裡），也是第 $k-1$ 步約束的結果（貢獻一個 $-\lambda_k$）。這就是「時間把前後兩步綁在一起」。

### 為什麼共態要逆著時間算？

$\lambda_k$ 是「$x_k$ 的價格」，而價格取決於**未來**會造成多少成本：
$$\lambda_k = \underbrace{\partial L/\partial x_k}_{\text{這一步付的}} + \underbrace{(\partial f/\partial x_k)^T\lambda_{k+1}}_{\text{傳給下一步的代價}}$$
算 $\lambda_k$ 要先知道 $\lambda_{k+1}$，所以只能從終點往回算。

### 邊界條件

| 終點 | 條件 |
|---|---|
| $x_N$ 自由 | $\lambda_N = \partial\phi/\partial x_N$（沒有 $\phi$ 就是 0） |
| $x_N$ 固定 | 直接用 $x_N = $ 給定值，$\lambda_N$ 變成待解的未知數 |

終點成本 $\phi$ 可以看成「終點固定」的**軟性版本**：權重越大，越接近強制到達。

### 兩點邊值問題：為什麼一般情況很難

$x$ 的已知條件在**頭**、$\lambda$ 的已知條件在**尾**，兩者又互相需要，所以只能整段一起解聯立。題目如果是非線性系統，通常只要求**寫出**這組方程（消去 $u$ 之後的狀態、共態方程），不要求解出來。

### 向量微分的技巧（非線性、向量系統一定會用到）

- 先分清楚 $u_k$ 是**純量**還是向量。純量時，$\partial H/\partial u_k$ 是一個數字
- 含多個變數相乘的項（例如 $x$ 乘 $u$）：**對誰微分，其他的就當常數**
- 先把同類項合併再微分，例如 $Mxu + bu = (Mx + b)\,u$
- 常用三條：$\dfrac{\partial}{\partial x}(\lambda^TMx) = M^T\lambda$、$\dfrac{\partial}{\partial u}(\tfrac12 u^TRu) = Ru$、純量的轉置等於自己（$\lambda^Tg = g^T\lambda$）
- **驗算技巧**：把多出來的項設成 0，看會不會變回熟悉的 LQR 方程

### LQR：猜 $\lambda_k = S_kx_k$ 破解兩點邊值

線性系統 + 二次成本 → 價格是線性的 → 猜 $\lambda_k = S_kx_k$。代入駐點條件得到**回授** $u_k = -K_kx_k$；代入共態方程得到 $S_k$ 的遞迴，也就是 **Riccati 方程**。

- 兩點邊值被拆成兩段：先**逆著時間**算完所有 $S_k$、$K_k$（離線），再**順著時間**跑 $u_k = -K_kx_k$
- $N$ 很大時 $K_k$ 會收斂成常數，對應 **DARE**
- **開迴路 vs 閉迴路**：一般 SOP 解出的是一串事先排好的 $u_k$（開迴路，遇到干擾不會修正）；LQR 給的是 $u_k = -K_kx_k$（閉迴路）

→ `midterm-prepare.md` §2

## 3. Lewis Ch 3：連續時間最佳控制

### 一切跟 Ch 2 一樣，只差一個負號

| | 離散 | 連續 |
|---|---|---|
| 狀態 | $x_{k+1} = \partial H/\partial\lambda_{k+1}$ | $\dot x = \partial H/\partial\lambda$ |
| 共態 | $\lambda_k = \partial H/\partial x_k$ | $-\dot\lambda = \partial H/\partial x$ ⚠️ |
| 駐點 | $\partial H/\partial u_k = 0$ | $\partial H/\partial u = 0$ |

**負號從哪來**：把離散式寫成「舊的 − 新的 = …」，而導數的定義是「新的 − 舊的」，方向相反。直覺上，$\lambda$ 是「剩下的成本」的斜率，時間往前走，剩下的越來越少。**記法：狀態正號、共態負號**（跟物理的 Hamilton 方程一樣）。

### 邊界條件四種情況

| 終點時間 $T$ | 終點狀態 $x(T)$ | 條件 |
|---|---|---|
| 固定 | 自由 | $\lambda(T) = \partial\phi/\partial x(T)$ |
| 固定 | 固定 | $x(T) = $ 給定值，$\lambda(T)$ 待解 |
| 固定 | 部分固定 $\psi = 0$ | $\lambda(T) = \phi_x + \psi_x^T\nu$ |
| 自由 | — | 再加一條 $(\phi_t + \psi_t^T\nu + H)\rvert_T = 0$ |

課本那條長公式的讀法：**能動的量（$dx(T)$、$dT$）前面的括號必須是 0；被固定的量那一項自動消失**。

### 一般問題的解題順序（線性系統常可手解）

1. 寫 $H$
2. 駐點條件：把 $u$ 寫成 $\lambda$ 的函數
3. **先解共態方程**：它常常跟 $x$ 無關，能直接解出來（只差一個未知常數）
4. 把 $u$ 代進狀態方程解出 $x(t)$，全部用那個未知常數表示
5. 用邊界條件定出常數

**看到共態方程右邊是 0 時**（例如系統裡沒有 $x$），$\lambda$ 就是常數，$u$ 也跟著是常數。

### 連續 LQR

猜 $\lambda = S(t)\,x$，得到
$$u^* = -R^{-1}B^TS\,x, \qquad -\dot S = A^TS + SA - SBR^{-1}B^TS + Q, \quad S(T)\text{ 給定}$$

- $K$ 比離散版簡單（少了 $B^TSB$），因為連續時每一瞬間的 $u$ 只推動狀態一點點
- 條件給在**終點**，所以從 $T$ 往回解

### 怎麼手解 scalar 的 Riccati 微分方程

1. 先寫出 scalar 版：把 $A, B, Q, R$ 換成數字，得到 $\dot s = (\text{$s$ 的二次式})$
2. 很多項會是 0（例如 $A = 0$ 或 $Q = 0$），先化簡
3. **分離變數**：$s$ 的部分移到一邊、$dt$ 移到另一邊
4. 兩邊積分，從 $t$ 積到 $T$，就能把終點條件 $s(T)$ 直接放進積分上下限
5. 解出 $s(t)$，**代 $t = T$ 驗算**
6. $K(t) = R^{-1}B\,s(t)$，閉迴路控制 $u = -K(t)\,x(t)$

（二次式有兩個根時用部分分式；只有 $s^2$ 一項時直接積分。）

### 穩態：ARE

$T \to \infty$ 時 $\dot S = 0$，得到 $0 = A^TS + SA - SBR^{-1}B^TS + Q$。

- ARE 是二次方程，**有多個解，要取正定的那個**。錯的根會讓閉迴路不穩定
- 需要 $(A, B)$ stabilizable、$(A, \sqrt Q)$ detectable，才保證有唯一正定解且閉迴路穩定
- 白話：不穩定的部分，控制要**推得動**、成本要**看得到**
- LQR 只跟 $Q$、$R$ 的**比例**有關

→ `midterm-prepare.md` §3

## 4. Lewis Ch 6：動態規劃

### Bellman 最佳性原理

> 最佳路線的任何後半段，本身也是最佳路線。

所以要知道「從這裡出發怎麼走最好」，只需要知道「從**下一站**出發最少要付多少」。

### 逆推的做法

$$J_k^*(x) = \min_u\big[\underbrace{L(x, u)}_{\text{這一步}} + \underbrace{J_{k+1}^*(\text{下一個狀態})}_{\text{之後的最佳值}}\big], \qquad J_N^* = \phi$$

- 從終點開始，對**每個狀態**都算出最佳值、記下該怎麼走
- 每一步**都要看「這一步 + 之後的最佳值」**，只看眼前最便宜的（短視）會出錯
- 題目要求**最大**（例如最大收益、最長路徑）時，把 $\min$ 換成 $\max$，其他完全一樣
- 最佳解不一定唯一（平手時兩條都對）
- 題目指定「用 principle of optimality」時，要寫出逆推的過程表，不能只列出所有路徑比較

### 格點 DP

狀態、控制只有幾個可能值時，每個狀態把每個允許的控制都試一次、挑最好的。

- **限制很好處理**：不允許的控制、會跑出範圍的控制，直接不列入候選
- 下一個狀態不在格點上時要**內插**

### 為什麼 DP 的答案天生是回授

算出來的是「每個狀態該怎麼做」的表，不管從哪裡出發、中途被干擾到哪裡，查表就好。

### HJB：連續時間的 Bellman

Bellman 方程的時間步取 $\Delta t \to 0$：
$$-\frac{\partial J^*}{\partial t} = \min_u\Big[L + \Big(\frac{\partial J^*}{\partial x}\Big)^Tf\Big] = \min_u H\Big(x, u, \lambda = \frac{\partial J^*}{\partial x}\Big)$$

- 括號裡就是 Ch 3 的 Hamiltonian，只是 $\lambda$ 換成 $\partial J^*/\partial x$
- 邊界條件：$J^*(x, T) = \phi(x)$
- 一般是很難解的偏微分方程；能手解通常是因為**猜得出 $J^*$ 的形式**

### 最重要的解題技巧：猜二次式、比較係數

LQR 的推導（Ch 2 的 DP 版、HJB 版、Ch 11 的 Bellman 版）都是同一個套路：
1. 猜 $J^* = \tfrac12 x^TSx$（或 $V = \tfrac12 x^TPx$）
2. 代入方程，對 $u$ 微分 $= 0$ 得到 $u^*$，再代回
3. 整理成 $x^T(\cdots)x = x^T(\cdots)x$
4. **因為對所有 $x$ 都成立**，括號裡的矩陣必須相等 → 得到 Riccati / Lyapunov 方程

（第 3 步若出現 $x^TSAx$ 這種不對稱的項，寫成 $\tfrac12 x^T(A^TS + SA)x$。）

### DP vs 變分法：什麼時候用哪個

| 情況 | 用 |
|---|---|
| 線性 + 二次成本 + 沒有限制 | Riccati（兩邊的交集） |
| 控制只能選幾個值、狀態有範圍、路徑問題 | DP |
| 高維非線性、只要一條軌跡 | 三個條件 + 數值解 |
| 控制有上下限、要解析解 | PMP |

DP 的弱點是**維度詛咒**：狀態每多一維，格點數就乘上一個大數。LQR 例外，因為 $J^*$ 是二次式，只要存一個矩陣。

## 5. Lewis Ch 11：強化學習

### 為什麼需要 RL

DP 和 Riccati 都要**事先知道模型**，而且是**逆著時間、離線**算的。RL 改成**順著時間、用量到的資料、線上**學。

**一定要分清楚**：
- DP：逆著時間、離線、要完整模型
- RL：順著時間、用經驗（causal experience）、線上

### 兩條 Bellman 方程

| | 方程 | 用途 |
|---|---|---|
| Bellman 方程 | $V^h(x_k) = r_k + \gamma V^h(x_{k+1})$ | 給**一個策略**評分 |
| Bellman 最佳性方程 | $V^*(x) = \min_u[r + \gamma V^*(x')]$ | 找最佳（= 離散 HJB） |

- $\gamma$：沒有終點時，讓無窮多項的總和保持有限
- 跟 Ch 6 的關鍵差別：**等號兩邊是同一個函數**（沒有終點可以起算），所以不能一路逆推，要**解方程**或**反覆疊代**
- 有限個狀態時，Bellman 方程就是一組**聯立線性方程**

### LQR 時這兩條方程變成什麼

用第 4 節的「猜二次式、比較係數」套路：
- Bellman 方程（固定策略 $u = -Kx$）→ **Lyapunov 方程**，對 $P$ 是**線性**的
- Bellman 最佳性方程（再對 $u$ 取最小）→ **DARE**，對 $P$ 是**非線性**的

要「證明」時，關鍵步驟就是：$V = \tfrac12 x^TPx$ 代入 → 策略或 $u^*$ 代入 → 「對所有 $x$ 成立」→ 比較矩陣。

### Policy Iteration vs Value Iteration

兩個基本動作：**評分**（算目前策略的 $V$）、**改進**（每個狀態改選讓 $r + \gamma V(x')$ 最小的動作，叫 greedy）。改進後的策略**不會更差**。

| | PI | VI |
|---|---|---|
| 評分 | **完整**解 Bellman 方程 | 只**代入一次** |
| 每輪計算量 | 大 | 小（最容易實作） |
| 收斂 | 輪數少 | 輪數多 |
| 起點 | 必須是**穩定**的策略 | **任意** |
| LQR 版本 | Hewer：反覆解 Lyapunov | Lyapunov 遞迴 = Ch 2 的 Riccati 逆推 |

- 疊代次數 $j$ **不是時間**
- 折衷：Generalized PI，評分時做幾次代入就好

### Q 函數：為什麼不需要模型

$$Q(x, u) = r(x, u) + \gamma V(x'), \qquad V(x) = \min_u Q(x, u)$$

- 用 $V$ 選動作：要知道 $u$ 會讓狀態跑去哪 → **需要模型**
- 用 $Q$ 選動作：直接比較 $Q(x, u)$ 的大小 → **不需要模型**
- LQR 的 $Q$ 是 $[x;\ u]$ 的二次式，從矩陣的區塊就能讀出 $K$，不必知道 $A$、$B$

### TD 與 Monte Carlo：怎麼把模型換成資料

Bellman 方程裡只有 $x_k$、$r_k$、$x_{k+1}$，這三個都量得到。估計不準時兩邊的差叫 **TD 誤差**，把它修到 0 估計就準了。

| | 精確計算 | Monte Carlo | TD |
|---|---|---|---|
| 需要模型 | 要 | 不用 | 不用 |
| 怎麼估 | 解方程 | 跑完**整趟**、跑**很多趟**取平均 | 走**一步**就修正 |
| 用幾條軌跡 | — | 很多條 | **一條** |
| 何時更新 | 離線 | 每趟結束 | **每一步**（線上） |

- 學習時要**探索**（persistent excitation）：一直照目前策略做，就看不到其他動作的效果
- 狀態太多時用 $V \approx W^T\phi(x)$ 近似（ADP、神經網路）
- 連續時間的 Bellman 方程含 $f$，IRL 改成「積一段時間」來避開 $f$

## 6. Żak Ch 3：可控性與可觀察性

**可控（reachable）**：控制能不能把狀態帶到任何地方？
**可觀察**：只量輸出，能不能反推出所有狀態？

| | 可控性 | 可觀察性 |
|---|---|---|
| 矩陣秩 | $\text{rank}[B\ AB\ \cdots\ A^{n-1}B] = n$ | $\text{rank}\begin{bmatrix}C\\ CA\\ \vdots\\ CA^{n-1}\end{bmatrix} = n$ |
| PBH | $\text{rank}[sI - A\ \ B] = n$，每個 $s \in \text{eig}(A)$ | $\text{rank}\begin{bmatrix}sI - A\\ C\end{bmatrix} = n$，每個 $s \in \text{eig}(A)$ |
| Gramian | $W = \int e^{-At}BB^Te^{-A^Tt}dt$ 非奇異 | $V = \int e^{A^Tt}C^TCe^{At}dt$ 非奇異 |
| 弱一點的版本 | stabilizable：控制不到的部分自己會穩定 | detectable：看不到的部分自己會穩定 |

- 兩者是**對偶**的：$(A, B)$ 可控 ⇔ $(A^T, B^T)$ 可觀察
- 連續時間 reachable ⇔ controllable；離散時間要 $A$ 非奇異才等價
- 跟 LQR 的關係：ARE 有好解需要 stabilizable + detectable

→ `midterm-prepare.md` 六、Żak Ch 3

## 7. Żak Ch 4：穩定性與 Lyapunov

### 判斷穩定：看 $A$ 的特徵值

| | 連續 $\dot x = Ax$ | 離散 $x_{k+1} = Ax_k$ |
|---|---|---|
| 漸近穩定 | 所有 $\text{Re}(\lambda) < 0$ | 所有 $\lvert\lambda\rvert < 1$ |

### Lyapunov 的想法：碗 + 往下滑

找一個「能量」$V(x) = x^TPx$：
- $P > 0$ → $V$ 是一個碗，只有原點最低
- 沿著軌跡 $V$ 一直下降 → 狀態只能滑到原點 → 漸近穩定

| | 連續 | 離散 |
|---|---|---|
| Lyapunov 方程 | $A^TP + PA = -Q$ | $A^TPA - P = -Q$ |
| 定理 | 漸近穩定 ⇔ 任給 $Q > 0$，解出的 $P > 0$ | 同左 |

- 實務：取 $Q = I$，解出 $P$，檢查 $P$ 是否正定（2×2：$p_{11} > 0$ 且 $\det P > 0$）
- ⚠️ **要從 $Q$ 解 $P$**，不能先選 $P$ 再算 $Q$（算出的 $Q$ 不定時，什麼都不能下結論）
- ⚠️ 「穩定」看 $A$ 的特徵值實部，「正定」看 $P$ 的特徵值，是兩件事；穩定的 $A$ 不一定負定
- 可以放寬成 $Q = C^TC$，只要 $(A, C)$ 可觀察

### 用 Lyapunov 算成本

$A$ 穩定時，$\int_0^\infty x^TQx\,dt = x_0^TPx_0$，其中 $A^TP + PA = -Q$。不用解微分方程、不用積分。這也是 LQR 裡「固定增益的成本」和 Ch 11「Bellman 方程 = Lyapunov 方程」的來源。

→ `midterm-prepare.md` 七、Żak Ch 4

## 8. Żak Ch 5：變分法、LQR、PMP

### Euler-Lagrange

找一條曲線讓 $\int F(t, x, \dot x)\,dt$ 最小，必要條件是
$$F_x - \frac{d}{dt}F_{\dot x} = 0$$

端點自由時要加 **transversality conditions**：$x$ 終點自由 → $F_{\dot x}\rvert_{t_1} = 0$；終點時間自由 → $(F - \dot xF_{\dot x})\rvert_{t_1} = 0$。

### Żak 的 LQR 推法

找 $V = x^TPx$ 讓 $\min_u(\dot V + x^TQx + u^TRu) = 0$。對 $u$ 微分得 $u^* = -R^{-1}B^TPx$，代回後「對所有 $x$ 成立」→ ARE。又是「猜二次式、比較係數」。

### Pontryagin 極小原理（PMP）

當 $u$ 有**硬性限制**（例如 $\lvert u\rvert \le 1$）時，$\partial H/\partial u = 0$ 可能沒有解，或解落在範圍外。改成：
$$u^* = \arg\min_{u \in U} H(x, u, p), \qquad \dot p = -\Big(\frac{\partial H}{\partial x}\Big)^T$$

**Bang-bang**：$H$ 對 $u$ 是**線性**的時候，最小值一定在邊界上，$u^* = -\text{sign}(\text{$u$ 的係數})$。切換次數取決於那個係數（switching function）會變號幾次。

### PMP 和其他方法的關係

- 沒有限制時，$\min_u H$ 就退化成 $\partial H/\partial u = 0$（Ch 3 的三個條件）
- PMP 的 $\min_u H$ 就是 HJB 括號裡的那個 $\min$，只是沿著一條軌跡來看

→ `midterm-prepare.md` 八、Żak Ch 5

## 9. 貫穿全課的五個動作

幾乎每一題都是這五步的組合：

1. **寫 Hamiltonian** $H = L + \lambda^Tf$（離散時配 $\lambda_{k+1}$）
2. **對 $u$ 微分 $= 0$**（有限制時改成在範圍內取最小）→ $u$ 寫成 $\lambda$ 或 $x$ 的函數
3. **寫共態方程**（連續時記得負號）
4. **寫邊界條件**（先判斷終點是固定還是自由）
5. **LQR 時猜二次式**，代入後「對所有 $x$ 成立」→ 比較矩陣

## 10. 易錯清單

- 連續時間共態方程漏掉負號：是 $-\dot\lambda = \partial H/\partial x$
- 離散 Hamiltonian 配的是 $\lambda_{k+1}$，不是 $\lambda_k$
- 終點固定時還寫 $\lambda_N = \partial\phi/\partial x_N$（終點固定時 $\lambda_N$ 是未知數）
- 離散 $K$ 和連續 $K$ 寫混：離散有 $(B^TSB + R)^{-1}$，連續只有 $R^{-1}$
- ARE 取錯根：要取**正定**（scalar 取正）的那個
- Riccati 微分方程的條件在**終點**，要從 $T$ 往回解
- 用「每一步挑眼前最便宜」代替 DP 逆推
- 把 PI / VI 的疊代次數 $j$ 當成時間
- 以為 PI 可以從任意策略開始（要穩定）
- 以為 DP 是順著時間、用經驗學（那是 RL）
- 矩陣的「$> 0$」是正定，不是每個元素都大於 0
- Lyapunov：先選 $P$ 再算 $Q$
- 混淆開迴路 $u^*(t)$ 和閉迴路 $u^*(x)$：題目問 closed-loop 時要給回授形式
